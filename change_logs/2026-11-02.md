## [22:30] 重构 WebUI 现代控制台视觉、接入本地 MLX-TTS 与原生抖音弹幕采集器

### 👤 提交信息

- **提交人**：liuleiyu (liuleiyu@fang.com)

### ✨ 功能要点

- 重构 WebUI 为 Modern Studio Console 现代设计规范，全面打通 Apple Silicon 本地 MLX 语音合成与 macOS 原生抖音弹幕采集

### 🔧 详细变动

- **WebUI 视觉体系**：制定 DESIGN.md 规范，采用纯净 Slate/珊瑚橙主题与无衬线字体栈，统一 40px 表单基线与操作坞浮层
- **语音合成（TTS）**：接入 custom_tts（MLX Audio 本地服务），支持音色/模型动态拉取、预填及克隆音色直接上传
- **抖音弹幕采集**：新增 integrations/douyin/collector.py 与管理脚本，纯 Python 直连 wss 转发至 Hub，告别 Windows 依赖
- **Live2D 舞台**：新增水族馆 1080P 动态背景视频及自动循环播放，精简弹幕字幕浮层
- **部署与协同**：优化 compose.yaml 目录实时挂载，新增 douyin-collector 服务 profile，忽略 .DS_Store 系统文件

### 💻 涉及代码

- `webui.py`: 重构全局样式表 PAGE_SCRIPTS 与自托管字体挂载，重绘右下角操作浮层
- `webui_app/pages/tts.py`: 新增本地 MLX Audio TTS 配置卡片、参数预填与音色拉取/上传
- `DESIGN.md`: 制定 Modern Studio Console 设计规范标准（色板、排版与几何对齐）
- `utils/audio_handle/my_tts.py`: 实现 custom_tts_api 请求本地 mlx-audio-tts-service
- `integrations/douyin/collector.py`: macOS 平台原生 Python 抖音直播弹幕采集器
- `Scripts/macos/collector.sh`: macOS 专用抖音采集器控制与自检脚本
- `compose.yaml`: 配置项目实时卷挂载与新增 douyin-collector 服务 profile
- `Live2D/stage-landscape.html`: 新增水族馆视频动态背景播放与兜底机制
- `tests/unit/test_custom_tts.py`: 新增本地 MLX TTS 接口单元测试
- `tests/unit/test_douyin_collector.py`: 新增抖音采集器协议解析单元测试
