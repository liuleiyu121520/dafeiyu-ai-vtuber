# 大肥鱼 AI 虚拟主播 · Docker / linux-arm64 运行依赖
#
# 由 requirements/ 的各个分组裁剪而来。裁剪原则：
#   1. 保留 WebUI + 主程序 + 弹幕 + LLM + TTS + 点歌 + BGM 的全部运行期依赖
#   2. 剔除 Windows 专有、或在 linux-arm64 上没有可用轮子的包
#   3. 剔除与 protobuf 7.x 硬冲突、且本机用不到的 Provider
#
# 与 requirements/core.txt + platform.txt 的差异清单：
#   - keyboard          保留（import 正常）；真正启用按键监听需要 /dev/input 与 root，容器内默认关闭
#   - azure-cognitiveservices-speech  无 linux-arm64 轮子（azure_tts 容器内不可用）
#   - pyvirtualcam / pyautogui / PyGetWindow  Windows/macOS 桌面专有
#   - opencv-python → opencv-python-headless   容器无 GUI，headless 才有稳定 arm64 轮子
#   - faiss-cpu / funasr / faster-whisper  体积巨大，本机不做本地 ASR / 向量检索
#   - google-generativeai  钉死 google-ai-generativelanguage<0.7，后者又钉 protobuf<5，
#                          与仓库要求的 protobuf 7.x 在解析层面互斥（gemini 容器内不可用）
#   - wenxinworkshop   走 gitee git 依赖，构建期不稳定，容器内不预装
#
# 保留但容器内不可用的（装了不影响启动，只是调用会失败，日志会提示）：
#   baidu-aip / SpeechRecognition（需要麦克风）
